See Model →

NVIDIA DGX Spark might be the best Christmas gift to get for your creator friend. Let me explain.

I built a simple model (with Fundamental Research Labs's Shortcut.ai -- incredible product btw) for frontier-video generation and found that it breaks even if you make more than 58 min (~92% of utilization) of AI video per week compared to renting a GPU or using API calls. Plus all content run and stored locally.

Assumptions

  • GPU performance for vid gen (token/sec): H100 200, DGX Spark 30
  • Workload: high-quality videos with 24 fps, 200 tokens per frame
  • H100 rate: $3.5 per hour
  • API call: $4 per 10 sec video (ref. OpenAI Sora)
  • DGX Spark useful life: 1 year
  • DGX Spark electricity cost: $0.03 per hour

What the Math Shows

Break-even vs API: ~3 min video/wk
Break-even vs GPU renting: ~58 min video/wk
Spark capacity: ~63 min video/wk
