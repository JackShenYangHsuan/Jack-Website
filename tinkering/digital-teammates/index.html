Digital Teammates for Content Creators

TL;DR

  • AI tool platform for content creators with specialized skills: comment analysis, competitor reports, video clipping, quote card generation.
  • Malleable software: merge any skills together and AI writes new tools at runtime, generating working code on the fly.
  • Three-agent architecture: Main (executes), Merge (writes new skills), Debug (auto-patches broken code).

The Problem

Content creators juggle 10+ tools: YouTube Studio, analytics platforms, video editors, thumbnail generators, comment scrapers. None of these tools talk to each other. Copy-pasting data between apps is the norm.

Generic AI assistants don't understand creator workflows. They can't access your YouTube data, send emails on your behalf, or upload to your Google Drive.

The Vision

What if you had digital teammates that handle your repetitive workflows autonomously? Each teammate specializes in one task: analyzing comments, generating reports, creating clips. You give an instruction, and they execute end-to-end in the background.

But here's where it gets interesting: these teammates aren't fixed. The software is malleable. Users and agents can remix skills, combine them, and reshape the entire experience. Drag "Comment Analysis" and "Quote Card Generator" together, and the system creates a new workflow that didn't exist before.

Malleable Software

Every skill becomes a building block. The Merge Agent reads source code, reasons about how pieces fit together, and writes new Python scripts at runtime. Users get flexibility. Agents get composability.

System Architecture

The system uses three distinct agents, each with a specialized purpose. This separation keeps execution fast while allowing complex skill creation.

The Three-Agent System

1 Main Agent

Executes skills by calling Python scripts via MCP, sends emails, uploads files. Handles all user-facing tool execution with streaming responses.

Claude 3.5 Sonnet • MCP tools • Streaming SSE

2 Merge Agent

Reads source skills, designs a unified workflow, validates config, tests end-to-end, and saves to database. Uses our most capable model for complex reasoning about skill composition.

Claude Opus • Custom merge tools • Up to 30 turns

3 Debug Agent

Automatically kicks in when a merged skill test fails. Classifies the error type, backs up the current version, applies fixes, and re-tests. Self-healing for merged skills.

Claude Sonnet • Error classification • Version rollback

Deep Dive: Claude Agent SDK Implementation

The core of the system is a custom MCP server that provides tools with user context (Google tokens, settings).

Creating the MCP Server

function createCustomMcpServer(userContext) {
  return createSdkMcpServer({
    name: 'rewire',
    version: '1.0.0',
    tools: [
      // Execute Python scripts (security whitelist)
      tool('run_bash', 'Execute bash command',
        { command: z.string() },
        async (args) => {
          // Only allow: python3 skills/*, cat, ls
          const env = {
            GOOGLE_ACCESS_TOKEN: userContext.googleTokens.accessToken,
            YOUTUBE_API_KEY: process.env.YOUTUBE_API_KEY,
            GOOGLE_AI_API_KEY: process.env.GOOGLE_AI_API_KEY
          };
          return execAsync(args.command, { env });
        }
      ),

      // Gmail integration
      tool('send_email', 'Send email via Gmail',
        { to, subject, body, htmlBody }),

      // Google Drive upload
      tool('upload_to_drive', 'Upload file to Drive',
        { filePath, folderId })
    ]
  });
}

Running the Agent

export async function* runAgent(message, options) {
  const mcpServer = createCustomMcpServer(options.userContext);

  const queryInstance = query({
    prompt: message,
    options: {
      systemPrompt: generateSystemPrompt(options),
      model: 'claude-3-5-sonnet-20241022',
      mcpServers: { rewire: mcpServer },
      allowedTools: [
        'mcp__rewire__run_bash',
        'mcp__rewire__send_email',
        'mcp__gmail__*',
        'mcp__google-workspace__*'
      ]
    }
  });

  // Stream events to client via SSE
  for await (const msg of queryInstance) {
    if (msg.type === 'assistant') {
      yield { type: 'content', content: msg.text };
    }
  }
}

Deep Dive: Skill Definition

Each skill is defined as a TypeScript object with settings, a prompt, and scripts. The prompt is executable: the agent follows it step-by-step without asking the user.

Skill Structure

const ytCommentReportSkill = {
  id: 'yt-comment-report',
  name: 'YouTube Comment Analysis',

  settings: [
    { key: 'emailRecipient', type: 'string' },
    { key: 'sendEmail', type: 'boolean', default: true }
  ],

  scripts: ['fetch_comments_api.py'],

  prompt: `
## YouTube Comment Analysis

### Step 1: Fetch comments
Use mcp__rewire__run_bash:
python3 skills/yt-comment-report/scripts/fetch_comments_api.py "{videoUrl}"

### Step 2: Parse JSON, generate HTML report

### Step 3: Send email (if sendEmail = true)
Use mcp__rewire__send_email:
- to: "{emailRecipient}"
- htmlBody: [full report]
  `
};

Key Pattern: Executable Prompts

Skill prompts are instructions, not documentation. The agent executes them step-by-step without asking for confirmation. Settings like {emailRecipient} are injected at runtime.

Deep Dive: Runtime Code Generation

This is where malleable software comes to life. When users drag 2-3 tools into a group, the Merge Agent doesn't just connect APIs. It writes new software.

Merge Agent Tools

Tool Purpose
read_skill Read source skill config.ts to understand structure
read_script Read Python scripts to understand implementation
validate_skill_config Check merged skill config before saving
test_skill Run end-to-end test with sample input
write_script Write new Python script if needed
create_merged_skill Save to database (Prisma)

Deep Dive: Self-Healing

When a merged skill fails during execution, the Debug Agent automatically diagnoses and fixes the issue.

Error Classification

function classifyError(error) {
  if (error.includes('ModuleNotFoundError')) {
    return { type: 'script', fix: 'Add missing import' };
  }
  if (error.includes('401') || error.includes('Unauthorized')) {
    return { type: 'permission', fix: 'Check API key' };
  }
  if (error.includes('SyntaxError')) {
    return { type: 'config', fix: 'Fix prompt syntax' };
  }
  return { type: 'runtime', fix: 'Investigate logs' };
}

Debug Flow

1. Backup current skill version → 2. Diagnose error → 3. Apply fix → 4. Re-test → 5. If still failing after 3 attempts, alert user for manual debug or rollback.

Key Takeaway

Software is becoming malleable. Instead of building every possible integration upfront, you build atomic skills and let AI compose them into workflows that didn't exist before. The agent writes real code at runtime.

The Merge Agent doesn't use templates or connect predefined APIs. It reads source code, reasons about how pieces fit together, and generates new Python scripts. If the merged skill breaks, the Debug Agent patches it automatically.

This is a fundamentally different paradigm: instead of developers anticipating every use case, users create their own tools by combining building blocks. The agent handles the software engineering.
