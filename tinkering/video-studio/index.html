One-person Content Studio - Re-creating Anthropic Commercial at Zero Cost

TL;DR

  • Built a full video production pipeline: from story discovery to final export with voiceover and music.
  • Runs entirely on my NVIDIA DGX Spark (128GB unified memory) - no cloud GPU costs, no API limits.
  • ComfyUI handles image generation (Flux) and video animation (Wan 2.2), orchestrated via a custom API client.
  • Web app built with Next.js connects to ComfyUI over local network, queues jobs, and polls for completion.
  • Benchmark: recreated Anthropic's "Keep Thinking with Claude" video at 90% quality in under 2 hours.

The Problem

Professional launch videos cost $3,000-$8,000 and take 4-8 weeks. DIY tools produce generic content. Most founders don't know how to structure emotional narratives.

At the same time, I had an NVIDIA DGX Spark sitting on my desk. Video generation is compute-heavy - perfect for local hardware. And the open-source models coming out of China (Hunyuan, Wan 2.2) are genuinely impressive.

The Vision

What if I could encode the creative process of a professional video producer into a guided workflow? Not just generate assets, but guide the entire creative journey from raw company info to polished video.

System Architecture

The system runs entirely locally on my DGX Spark. No cloud dependencies except for LLM calls (OpenRouter) and optional audio generation (ElevenLabs, Suno).

The 8-Phase Pipeline

1 Discover

AI-guided interview extracts the emotional story. Not marketing speak - the raw, visceral pain and transformation. Outputs a structured Story Brief.

OpenRouter API → Claude 3.5 Sonnet (streaming)

2 Style

Paste reference video URLs (YouTube). Gemini analyzes them and extracts style signals: pacing, color palette, camera movements, energy arc.

Gemini API (video understanding)

3 Storyboard

AI generates scene-by-scene breakdown with beat labels, durations, voiceover scripts, image prompts, and motion prompts. User can edit, reorder, lock scenes.

OpenRouter API → LLM generates structured JSON

4 Images

Generate keyframe images for each scene using Flux. Style guide injected into every prompt for consistency.

ComfyUI → Flux (local, 1280x720 PNG)

5 Videos

Animate each keyframe into 3-5 second video clips using Wan 2.2 image-to-video. Motion prompts control camera movement and animation.

ComfyUI → Wan 2.2 (local, 24fps MP4)

6 Stitch

Timeline editor with drag-drop reordering, trim handles, transitions (cut/fade/dissolve), and playback speed control.

FFmpeg (local rendering)

7 Audio

Generate voiceover from scene scripts (ElevenLabs) and background music (Suno). Mix with ducking, fade in/out.

ElevenLabs API + Suno API + FFmpeg

8 Export

Final render with all layers. Output: MP4 (H.264 + AAC), 1280x720 or 1920x1080.

FFmpeg (local)

Deep Dive: ComfyUI Integration

This is the technical heart of the system. ComfyUI runs as a server on the DGX Spark, and the web app communicates with it via HTTP API.

ComfyUI Server Setup

ComfyUI exposes a REST API when running. On my DGX Spark, it's accessible at http://192.168.4.48:8188.

# Start ComfyUI with network access
python main.py --listen 0.0.0.0 --port 8188

The ComfyUI Client

I built a TypeScript client that handles the full generation flow:

class ComfyUIClient {
  // 1. Queue a workflow for execution
  async queuePrompt(workflow) {
    const response = await fetch(`${serverUrl}/prompt`, {
      method: 'POST',
      body: JSON.stringify({ prompt: workflow, client_id })
    });
    return response.json().prompt_id;
  }

  // 2. Poll until complete
  async waitForCompletion(promptId) {
    while (Date.now() - start < maxWait) {
      const history = await fetch(`${serverUrl}/history/${promptId}`);
      if (history.status?.completed) return history;
      await sleep(1000);
    }
  }

  // 3. Fetch the generated image
  async getImage(filename) {
    return fetch(`${serverUrl}/view?filename=${filename}`);
  }
}

Workflow Injection

ComfyUI workflows are JSON graphs. The client dynamically injects the user's prompt into the appropriate node:

// Find the prompt node and inject text
const promptNode = workflow[promptNodeId];
if (promptNode.inputs.text) {
  promptNode.inputs.text = userPrompt;
} else if (promptNode.inputs.positive) {
  promptNode.inputs.positive = userPrompt;
}

// Randomize seed for variety
if (node.class_type === 'KSampler') {
  node.inputs.seed = Math.floor(Math.random() * 2**32);
}

"You are a creative director conducting a discovery interview
for a startup launch video. Your goal is to extract the
emotional truth of the company's story - not marketing speak.

Ask one question at a time. Listen carefully. Follow up on
emotional cues. Dig deeper when answers are generic.

After 5-7 questions, summarize into a Story Brief with:
- Pain (raw, visceral)
- Solution
- Transformation (before → after)
- Emotional Stakes
- Unique Angle"
